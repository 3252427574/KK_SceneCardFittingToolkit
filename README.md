# 场景卡套档工具箱 (Scene Card Fitting Toolkit) v1.9.3

Koikatu / Koikatsu 的 CharaStudio 插件。

## 安装

把 `BepInEx` 文件夹里的内容合并到游戏根目录(与 `Koikatu.exe` / `CharaStudio.exe` 同级):

```
游戏根目录/
└── BepInEx/
    └── plugins/
        ├── KK_SceneCardFittingToolkit.dll   ← 插件主文件
        └── KKPEHeightLock/                  ← 资源目录(图标)
            └── icon.png                     ← 工具栏图标(可替换,任意尺寸)
```

> 需要已安装: BepInEx 5、KKAPI、KKPE、KK_MaterialEditor、Timeline、VRGIN_KKCS、KKCharaStudioVRPlugin(Ermin)。

## 功能

- **身高/身材锁定**: 锁定 cf_n_height 身高,不被姿势动画覆盖;替换角色时可保留体型
- **场景替换**: 加载场景后按性别自动替换、随机替换(女/男/全部)、立即替换,可保留姿势/服装
- **场景播放器**: 上/下一场景、加载、删除、场景子目录、FSS(自动扫描全库,含子目录)
- **Timeline**: 播放/暂停/停止、CAM 相机跟随开关
- **服装预设**: 校服1/2、体操、泳装、社团、便服、睡衣 一键切换 + 部件三态(穿/半脱/脱)
- **场景工具**: 一键去无用球体、一键去马赛克(可设加载场景自动执行)
- **VR 第一人称**: 视角跟随角色双眼,摇杆转头(俯仰/偏航,摄像机位置固定),参数可调
- **场景人物列表**: 列出场景全部角色,一键在工作室选中(换人即作用于所选角色)
- **VR 悬浮菜单**: 完整复刻桌面菜单,分页浏览,VR 内直接选角色卡(缩略图)/选子目录/选场景人物,跟随眼前,带命中光标

## 更新日志 v1.9.3

- **修复: 场景播放器加载场景后镜头锁死/VR 手消失** — 之前直接调用 studio.LoadScene 跳过了 Studio 完整的加载流程。现改用 Studio 原生加载协程(Studio.LoadSceneCoroutine),与 UI 加载完全一致,加载后 VR 相机/手柄自动恢复。
- **新增: 随机场景** — 场景播放器新增「随机场景」按钮(桌面与 VR 菜单),从全库随机加载一张场景(排除当前)。
- **修复: 场景播放器无法推进** — ◀▶ 只加载固定的头/尾两张场景卡、进度不变。原因: 场景列表只扫描根目录(你的场景都在分类子目录里)且刷新时重置了当前索引。现改为递归扫描全部子目录、刷新时保留当前索引,◀▶ 可连续切换全部场景。
- **修复: 换人后操作仍作用于第一个角色** — 服装预设/部件三态等只认第一个选中的角色。现改为实时读取当前工作室选中角色,人物列表选中谁就作用于谁。
- **修复: VR 第一人称俯仰转头时摄像机脱离头部** — 低头/抬头时头显位置绕圈飞走。原因: 头显偏移被俯仰旋转放大 + Ermin 插件把右摇杆上下识别为 Y 轴高度移动与俯仰冲突。现已隔离冲突并固定摄像机位置(只转朝向,位置不动)。
- **调整: VR 按键映射** — 原左手 Y 呼出菜单后左手无法选择,现改为: 右手柄 B 键呼出/关闭菜单(配合右手激光操作),左手柄 Y 键改为第一人称 POV 开关。
- **修复: 菜单选择** — 命中点增加青绿色圆环光标,选按钮更直观。
- **优化: 场景替换** — 支持保留姿势/服装、多选角色立即替换。

## 配置

配置文件 `BepInEx/config/com.kkpeheightlock.cfg`(首次运行后生成),或游戏内 F1 设置界面调整。

## 使用

- 桌面: 工作室里点左侧工具栏图标(深红菱形)打开菜单;F12 开关 VR 第一人称。
- VR: 右手柄 B 键呼出悬浮菜单;`◀ ▶` 按钮翻页;右手射线指向按钮、扳机确认;左手柄 Y 键开关第一人称。

## 源码

`源码/` 目录包含 `KKPEHeightLock.cs`、`VRFloatingPanel.cs` 和 `KKPEHeightLock.csproj`(net35)。用 dotnet SDK 构建:

```
cd 源码 && dotnet build -c Release
```
